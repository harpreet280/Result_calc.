# Description
> A simple R programming project that calculates a student's total marks, percentage, grade, and pass/fail result based on marks entered by the user.

# Tools used
> R Programming
> RStudio

# Features
> Takes student name and roll number as input accepts marks for 5 subjects.
> Calculate total marks.
> Calculate percentage.
> Assign grade using if-else.
> Determines Pass/Fail status.
